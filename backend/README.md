# Medical Store Backend

## 1. PostgreSQL
Create the database:

```sql
CREATE DATABASE medical_store;
```

Then run:

```bash
psql -U postgres -d medical_store -f sql/schema.sql
```

## 2. Environment
Copy `.env.example` to `.env` and set your PostgreSQL password and JWT secret.

## 3. Install and seed

```bash
npm install
npm run seed
```

The existing login remains:

- Username: `admin`
- Password: `admin123`

Only the admin account is seeded. Products, suppliers, purchases and bills remain empty until entered through the UI.

## 4. Start

```bash
npm run dev
```

Backend: http://localhost:5000
Frontend expects: http://localhost:5000/api

### New database objects

The current schema adds `customers` and `sale_day_sequences` and upgrades `sales` with `customer_id` and `payment_method`.

Run the complete `sql/schema.sql` against the `medical_store` database after replacing the old schema. The SQL uses `IF NOT EXISTS` / safe `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` for the new fields.

### Sale ID

Sale IDs are generated by PostgreSQL-backed daily counters and look like:

`CC-20260927-0001`

The number increments for every sale on that date, so the frontend does not decide the final unique ID.
